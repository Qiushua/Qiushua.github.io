这篇文章是给未来的自己（和偶然点进来的你）准备的速查表：本站支持哪些写法，每一种长什么样。

想写新文章时，建议直接复制这个文件的框架，改掉开头的配置和正文即可。

## 标题与段落

正文用 `##` 作为一级小标题，`###` 作为二级小标题。右侧的目录会自动抓取它们，所以**别跳级**（比如从 `##` 直接到 `####`）。

段落之间空一行。中文排版上，中英文之间、数字与汉字之间会自动保留视觉间距，不需要手动敲空格。

## 强调与链接

- **加粗** 用两个星号
- *斜体* 用一个星号
- ~~删除线~~ 用两个波浪号
- `行内代码` 用反引号
- [普通链接](https://example.com) 用方括号加圆括号

链接会在新窗口打开（站外链接由脚本自动处理），站内链接直接用相对地址即可。

## 列表

无序列表用 `-`：

- 第一项
- 第二项
  - 缩进两个空格表示子项
  - 再一层也可以
- 第三项

有序列表用数字：

1. 先读需求
2. 再写代码
3. 最后写文档

## 引用

> 设计不是让东西好看，而是让东西变得更好用。
>
> —— 某个我记不清名字的设计师

引用可以有多段，用空行加 `>` 分隔即可。

## 代码

行内代码：执行 `bundle exec jekyll serve` 启动本地预览。

代码块需要标注语言，这样才有语法高亮：

```bash
# 安装依赖并启动本地服务
bundle install
bundle exec jekyll serve --livereload
```

```javascript
// 计算阅读时间的小函数
function readingMinutes(words, wpm = 300) {
  return Math.max(1, Math.ceil(words / wpm));
}

console.log(readingMinutes(1500)); // 5
```

```python
# 统计文章字数
def word_count(text: str) -> int:
    return len(text.replace("\n", "").strip())
```

代码块右上角有一个"复制"按钮，点一下就能拿走整段代码。

## 表格

| 项目 | 说明 | 是否必填 |
| --- | --- | :---: |
| `title` | 文章标题 | 是 |
| `date` | 发布日期 | 是 |
| `categories` | 分类，一个或多个 | 否 |
| `tags` | 标签，用于检索 | 否 |
| `cover` | 封面图路径 | 否 |

列的对齐方式由表头分隔行里的冒号决定，`:---:` 表示居中。

## 图片

图片放在 `assets/images/posts/` 目录下，然后用标准的 Markdown 语法引用：

```markdown
![图片说明](/assets/images/posts/你的图片.jpg)
```

想加图注，可以用 HTML 的 `figure` 标签：

```html
<figure>
  <img src="/assets/images/posts/你的图片.jpg" alt="说明">
  <figcaption>图片下方的小字说明</figcaption>
</figure>
```

点击正文里的图片可以放大查看。

## 需要避免的写法

- ❌ 不要用一级标题 `#`，它会和文章标题打架
- ❌ 不要直接写两对花括号连起来的模板语法，Jekyll 会尝试解析它（需要展示时用 `&#123;&#123;` 转义）
- ❌ 不要手动给标题加锚点，脚本会自动生成
- ❌ 图片不要超过 500KB，最好先压缩
